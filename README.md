# Brain Tumor Detection using YOLOv8  
A desktop-based medical imaging application that uses **YOLOv8** deep learning models to detect **brain tumors** from MRI scans.  
This project provides an interactive **Tkinter GUI** with real-time visualization, system logs, and detection results.

---

## Features
- **MRI Image Detection**  
  Upload any MRI image (JPG, PNG) and detect tumors instantly.

- **MRI Video Scan**  
  Run tumor detection on MRI video files frame-by-frame (MP4, AVI, MOV).

- **Live Webcam Demo**  
  Demonstrates the model detecting bounding boxes in real-time.

- **Beautiful GUI (Matrix Medical Theme)**  
  - Live status updates  
  - Rotating loader animation  
  - System logs  
  - Detection confidence display  
  - Highlighted tumor bounding boxes  

- **YOLOv8 Model Integrated**  
  - Fast  
  - Accurate  
  - Lightweight  
  - Supports CPU & GPU
